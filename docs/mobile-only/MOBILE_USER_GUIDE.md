# 手机端用户指南（Mobile User Guide）

> 状态：**当前有效 / IMPLEMENTED / HOST TESTED**（真机流畅度和完整扫描仍需 DEVICE SMOKE）。最后核对：2026-08-10。

## 首页

首页大型“新建扫描”和菜单中的“开始门店扫描”都进入同一套全手机扫描配置；“门店地图”管理同一个地图库；“处理历史扫描”和“历史结果”负责结束后的手机处理与查看。自由扫描建图、原始数据录制和旧 PC 预处理兼容入口位于“实验与兼容工具”，不再作为主流程。

## 第一次使用

门店地图 → `+` → 选择“导入 XLSX / CSV / JSON”或“导入已有 PC 地图包”。

- 原始表格会先在后台复制到 App 私有目录，再严格解析并编译。进度页显示复制、解析、业务身份、楼层、道路图、逐层距离场、空间索引、预览、manifest、自验证、提交和注册等真实阶段。
- 完成页显示地图名、门店 ID、`prior_map_id`、package SHA、canonical SHA、楼层数、有效/忽略元素、警告和源文件信息。不能只以“导入成功”代替这些结果。
- 正式 PC v2 地图包会按原字节复制、production integrity 复验并注册到同一个地图库；缺 `store_id`、canonical identity 或内容完整性不合格的旧包必须重新生成，不能进入扫描。

## 扫描

开始门店扫描 → 选择门店地图 → 选择楼层 → 在预览图上点击起点 → 调整位置与朝向 → 开始扫描 → 扫描价签 → 结束扫描。

- 地图支持 1×—8× 捏合缩放、单指平移、双击放大/复位和点击选点。
- 起点可用上/下/左/右方向键微调，步长可选 0.1 m、0.5 m 或 1.0 m。
- 朝向使用东 0°、北 90°、西 180°、南 270°以及左转/右转 15°，不使用横向滑杆。
- 从首页直接进入时左上角显示“关闭”；从地图库进入时使用系统返回按钮和返回手势。离开配置页会取消尚未完成的启动，不会让扫描在后台自行开始。
- 第一次使用相机时，App 会先完成系统权限请求；授权后重新执行完整的地图/身份/权限检查，再提交启动。拒绝权限时保持在配置页并提供“打开设置”。
- 普通 Debug 构建没有正式 build identity，只用于导入和 UI 调试。真实门店扫描请使用 `RTABMapApp-QualifiedDevice` scheme 的 Release Run；否则开始按钮会明确提示构建不具资格。

点击开始后，地图匹配器、会话目录、连续 SQLite 数据库和 sidecar writer 在后台准备。只有相机、RTAB-Map 录制、receipt 和 workflow context 都成功后才进入扫描；失败或取消会自动停止并回滚，不会留下没有结果记录的后台扫描。

用户不输入坐标数值、矩阵、RTAB-Map node、JSON 或因子权重。

## 扫描结束

结束扫描 → 安全保存 → 自动处理 → 快速图优化 →（必要时一次现有全图优化）→ 最终轨迹 →
价签最终定位 → 自动质量门 → 生成工作簿

若两条优化路径均未通过，或优化结果没有任何可发布轨迹节点，App 会显示“需要重新扫描整个会话”，并生成持久的 `RESCAN_SESSION` 任务终态。该次处理不会在手机上进行 True sensor Deep，也不会生成 PriceTags、DevicePositions、工作簿或普通历史结果；即使 App 在 outcome、checkpoint 或 task 状态提交窗口中断，重启后也会先验证专用不可变 outcome 再恢复该终态，不会把同一任务静默重跑成低质量结果或改写成普通失败。

## 结果页

自动通过价签：N；需要补扫价签：N；有效手机位置秒数：N；不可用区间：N；处理耗时；结果地图预览。
操作：[导出 XLSX] [查看补扫任务] [查看诊断摘要]

历史结果若校验失败会从正常列表隔离到审计 quarantine，并在诊断中显示；App 不会把损坏结果当作成功结果，也不会自动删除原 payload。

## 无 PC

从原始地图到工作簿的最终用户流程可以完全不使用 PC。导入正式 PC v2 地图包只是同一地图库支持的兼容来源，不会创建第二套配置页、启动逻辑或扫描系统。
