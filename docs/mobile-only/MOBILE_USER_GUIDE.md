# 手机端用户指南（Mobile User Guide）

> 状态：DESIGNED（V1 界面流程；真机 UX 验收随 DEVICE SMOKE PASS 后更新）

## 首页

[门店地图] [开始扫描] [补扫任务] [历史结果] [设置与诊断]

## 第一次使用

门店地图 → 导入地图 → 选择 XLSX / CSV / JSON → 自动识别格式 → 严格验证 →
坐标预设确认（门店图：左上角为原点 / CAD 图：左下角为原点）→ 生成地图 → 查看预览 → 使用地图

## 扫描

开始扫描 → 选择门店地图 → 选择楼层 → 在预览图上点击起点 → 旋转方向箭头 →
设备检查 → 开始扫描 → 扫描价签（识别条码 → 锁定 ROI → 0.8~1.5 秒多帧）→ 结束扫描

用户不输入坐标数值、矩阵、RTAB-Map node、JSON 或因子权重。

## 扫描结束

结束扫描 → 安全保存 → 自动处理 → 快速图优化 →（必要时深度重处理）→ 最终轨迹 →
价签最终定位 → 自动质量门 → 生成工作簿
