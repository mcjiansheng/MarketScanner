# MarketScanner 地图辅助定位用户操作手册

> 文档状态：**当前有效**。最后核对日期：2026-07-25。
>
> 当前范围是单一楼层；楼层内部少量竖直位移会保留在原始三维数据中，但不参与二维先验地图定位。NFC 入口保持关闭。

## 手机自由扫描

1. 在首页选择“自由扫描”。
2. 检查相机权限、可用空间和保存位置。
3. 按既有流程开始、暂停、继续和结束扫描。
4. 等待结束处理和外部复制完成，不要在复制期间关闭应用。

自由扫描不需要先验地图，也不会出现价签定位复核步骤。输出仍是连续单 SQLite 数据库及兼容 sidecar。

## 手机已有地图辅助扫描

1. 选择“已有地图辅助扫描”。
2. 导入经过 Map Studio 校验的先验地图包；应用会验证整个包的文件集合、SHA‑256 和跨文件关系。
3. 选择唯一楼层，在地图上选择起点和朝向。
4. 完成设备检查后开始扫描。
5. 主界面关注定位状态、当前通道、最近轨迹和待复核价签；工程诊断默认折叠。
6. 需要扫码时点击价签扫描按钮。识别复用当前 ARFrame，不会启动第二相机。
7. 确认价签业务字段；弱定位、过期对齐或深度证据不足的结果必须进入待复核。
8. 正常结束并等待落盘、数据库关闭和外部复制完成。

## 定位弱或丢失

- “定位较弱”时继续缓慢前进，面向货架端头、柱子或交叉口，避免快速转动。
- “定位丢失”且偏差可能超过局部搜索窗口时，系统不会自动跨通道跳转；停止移动并使用人工重定位重新选择当前位置和方向。
- 人工重定位只更新地图对齐，不重置 ARKit 世界坐标，也不改写原始数据库。

## PC 自由扫描处理

1. 在 Supermarket Map Studio 选择单设备、历史阶段或多设备入口。
2. 选择已正常完成的会话和新的空输出目录。
3. 保持 PC 离线优化开启并一键生成。
4. 检查质量报告、2D/3D 预览和警告，再发布成果。

## PC 地图辅助扫描处理

1. 打开“先验地图会话优化”。
2. 选择与手机会话 hash 匹配的先验地图包。
3. 选择地图辅助扫描会话；会话必须已完成、仅含一个连续数据库且不存在 `live_checkpoint.json`。
4. 选择新的空结果目录；如需重放既有复核，可选择同一地图/会话生成的 `manual_edits.json`。
5. 点击“一键优化并进入复核”。处理顺序是 RTAB‑Map 离线重处理、地图坐标 SE(2) 派生优化、价签重关联和质量门。
6. 检查在线/RTAB‑Map/离线轨迹、weak/lost 区间、拒绝约束、价签和质量门结果。
7. 只有 `automatic_publish_allowed=true` 才可自动发布；否则必须完成复核。

## 价签与轨迹复核

- 可设置轨迹锚点、禁用错误约束、把区间指定到候选通道，或修改价签的货架、侧面、offset 和高度。
- 区间指定通道的新值格式为 `{"aisle_id":"C1","start_timestamp":12.0,"end_timestamp":30.0}`；时间戳取轨迹/问题数据中的会话时间。
- 可批准单个价签或批量批准明确的高置信价签 ID。
- 每次操作写入与地图包、源会话 hash 绑定的 `manual_edits.json`；撤销/重做通过游标重放。
- 自动重算不会静默覆盖已重放的人工价签字段。
- 最终使用 `localized_price_tags.json/.csv/.geojson` 和 `shelf_tag_index.json`；保留 `audit_log.jsonl` 作为操作审计。

## 数据备份与失败恢复

- 保留手机原始 `SupermarketSession-*`，不要在原目录运行 PC 优化。
- 将每次 PC 处理写入新的 `MapStudio-Localized-*` 目录。
- 若手机会话含 `live_checkpoint.json`，先回到手机正常结束扫描；不要强行优化可能仍在写入的数据库。
- 若 PC 任务失败，原始数据库不受影响。修正输入后选择新的空目录重试。
- 复核迁移时同时备份地图包、原始会话、结果目录和 `manual_edits.json`；hash 不匹配的编辑日志会被拒绝。
