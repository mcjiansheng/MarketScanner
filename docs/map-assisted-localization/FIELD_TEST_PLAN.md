# 正式现场测试计划

> 文档状态：**阶段三预案，当前不执行**。最后核对日期：2026-07-24。

阶段一和阶段二通过独立审查前，不安排正式超市场景，避免用现场时间替代可重复测试。

正式测试前置条件：

- 阶段一 review 通过；
- 阶段二实时匹配、置信度、Vision 扫码和价签测量 review 通过；
- 办公室回放、热状态、磁盘和中断恢复干跑通过；
- 先验地图版本、现场楼层和入口控制点核对完成。

阶段三现场记录至少包括：

- 设备型号、iOS、地图 SHA-256、应用 commit；
- 起点/方向控制点；
- 蛇形路线、交叉口、柱子和重复平行通道；
- tracking 中断和人工恢复；
- 已知货架位置与测量控制点；
- 标签位置真值、手机位置和估计标签位置；
- 原始数据库 hash、全部 sidecar、PC 参数和结果 hash；
- 自由扫描对照组。

阶段一禁止用“办公室预览看起来正确”替代现场绝对精度结论。
