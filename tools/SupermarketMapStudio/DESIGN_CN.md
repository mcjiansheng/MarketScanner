# Supermarket Map Studio 设计与功能说明

## 目标

Supermarket Map Studio 是运行在本机浏览器中的离线可视化工作台。它面向已从 iPhone 导出的 `SupermarketSession-*` 目录，提供单设备分阶段建图、多设备合并、二维地图生成、质量检查和可交互的二维/三维预览。

除启动工作台外，使用者不需要输入 Python 命令、编辑 JSON 文件或在终端手动执行合并脚本。

## 第一版功能范围

1. 选择一个单设备会话目录，自动发现并合并其中的 `segment_*`，创建快速地图包或分阶段地图包。
2. 从界面添加阶段、填写分段范围和位姿校正；未添加阶段时自动按每个 segment 建立 stage。
3. 添加多台手机的会话目录，设置公共起点对齐以及每台设备的平移、旋转初值，生成统一 2D 地图包。
4. 选定会话后，默认在其内部生成独立的 `MapStudio-*` 输出子目录；非空输出目录会被拒绝，避免覆盖旧成果或原始扫描数据。
5. 显示任务状态、错误信息、输出路径、质量警告和待复核项。
6. 在界面内平移、缩放二维预览图。
7. 从 RTAB-Map 节点深度图、相机标定和位姿重建受控规模的三维点云，在界面内用 WebGL 旋转、缩放，并显示平面栅格与各 segment 轨迹。
8. 打开输出目录以及导出后的 `preview.png`、GeoJSON、JSON 报告等成果文件。
9. 对输入会话执行只读检查，显示 segment、数据库、节点与价签数量。

## 明确的边界

- 现有映射工具的核心产物仍是二维地图包；三维视图现已包含由 RGB-D 节点重建的真实几何点云，但不是完整高精度纹理 mesh。
- 不提供自动 ICP、全局图优化、纹理融合或编辑 mesh。这些需要后续接入 RTAB-Map/C++ 提取和配准模块。
- 不修改原始数据库、sidecar 或价签记录；校正仅影响本次输出。
- 通过“停止映射”保存的最后一个 segment 必须先在 iOS 端导出完成，再导入 PC。

## 架构

```text
浏览器 UI
  -> HTTP JSON API（本机 127.0.0.1）
  -> Map Studio Python 编排层
  -> supermarket_staged_map.py / supermarket_multi_device_map.py
  -> Map2D 输出包 + preview_3d.json
  -> 2D Canvas / 3D WebGL / 报告面板
```

后端只使用 Python 标准库：`http.server`、`sqlite3`、`threading`、`json`、`zlib` 和 `webbrowser`。深度 PNG 解码、相机标定解析与点云生成同样不依赖 OpenCV/PCL，因此无需 `pip install`、Node.js、Qt、Electron、Docker 或网络服务。点云预览均匀抽样关键帧并限制像素密度，避免大型会话把全部深度像素一次送入浏览器。

## 交互与数据流

### 单设备

1. 通过“选择文件夹”选择一个 `SupermarketSession-*` 目录。
2. 选择空输出目录；需要人工微调时，添加阶段并填写名称、分段范围（如 `1-3,5`）及 dx、dy、yaw。
3. 点击“生成单设备地图”。
4. 工作台调用 `supermarket_staged_map.py` 的 Python API。
5. 界面展示二维预览、三维预览、质量报告和输出文件。

### 多设备

1. 重复添加每台手机的会话目录。
2. 对每台设备设置 ID、可选 `dx`、`dy`、`yaw` 初值；默认启用共同起点对齐。
3. 选择空输出目录，点击“合并多设备”。
4. 工作台生成临时多设备配置并调用 `supermarket_multi_device_map.py`。
5. 通过地图预览和报告检查重叠、冲突、变换与待复核项。

## 跨平台策略

| 平台 | 启动方式 | 文件夹选择 | 预览 |
| --- | --- | --- | --- |
| macOS | `./start.sh` | 本机文件夹对话框 | 默认浏览器 |
| Linux | `./start.sh` | 本机文件夹对话框；缺少 Tk 时可粘贴路径 | 默认浏览器 |
| Windows | 双击 `start.bat` | 本机文件夹对话框 | 默认浏览器 |

文件夹选择使用 Python 自带的 Tk 对话框；它不可用时，界面保留路径输入框作为无损回退。浏览器与服务端只绑定 `127.0.0.1`，不向局域网暴露扫描数据。

## 质量与安全规则

1. 所有会话目录和可选点文件必须存在且可读。
2. 输出目录必须为空或不存在。
3. 每个任务有独立状态；后台线程运行时 UI 不会冻结。
4. 文件下载/预览接口仅能读取已登记任务的输出目录中的文件，不能用 URL 浏览任意本机路径。
5. 输出保留原工具的 `source_manifest.json`，用于输入 hash 追溯。

## 验收标准

1. 仅凭 Python 3 即可启动，不依赖第三方包。
2. 单设备和多设备示例会话均能通过 UI API 产出完整地图包。
3. 产物含 `preview.png`、`preview_3d.json`、`quality_report.json` 与相应 manifest。
4. 2D 画布支持缩放和拖拽；3D 画布支持旋转、缩放和重置。
5. 自动化测试覆盖输入检查、单设备任务、多设备任务与结果文件访问。
